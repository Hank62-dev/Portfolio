# SpaceHank robot employees

These robot GLBs are from the FORGE character collection by Ramon Linares:
https://github.com/RamonLinares/atlas-09

The collection is released under CC0 1.0 according to the repository's asset
license. The project includes rigged models and baked animation clips. SpaceHank
uses the downloaded GLBs as employee variants:

- atlas-09.glb
- seraph-03.glb
- scorpio-05.glb
- titan-06.glb
- ronin-04.glb

The browser runtime selects a robot variant per agent and plays the first
available idle/rest/run animation clip from each GLB.
